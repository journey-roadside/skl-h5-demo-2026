# skl-h5-demo-2026

社科联二期项目建设（SKLQ2）H5 端演示原型仓库。

- 产品名称：湖北社科数据信息联盟
- 仓库用途：承载公众号 H5 端可运行原型
- 当前版本：**v3**（多页站点：数字人首页 · 对话 · 历史 · 设置 + 404 / 500）
- 历史版本：`v1` `v1.1` `v2` `v2.1` `v2.2` 为 tag；`v1.1/`、`v2.2/` 两个目录是站内存档，各自带一份 `h5v2/` 与脚本副本

## 页面与入口

首页 → 对话页：顶栏「对话模式」钮跳 `chat.html`。键盘钮仍是页内输入条（不跳转），
「立即对话」走扫码授权。

对话页顶栏按登录态显隐：

| 元素 | 未授权 | 已授权 · 空对话 | 已授权 · 有对话 |
|---|---|---|---|
| 会话标题 / 历史 | 隐藏 | 显示 | 显示 |
| 新建对话 | 隐藏 | 隐藏 | 显示 |

进入对话页未授权会直接弹扫码窗；「发送」「开始录音」也会拦一次。

## 扫码授权（演示）

真机微信内 `auth.js` 的 `boot()` 在加载时即授权，看不到扫码窗。非微信端
（演示主场景）用占位二维码把「扫码 → 登录」演出来：**点二维码 = 已扫码**，
随即写入演示身份（昵称 / 头像 / 脱敏手机号），再补做刚才被拦下的动作。

`js/auth.js` 同时保留手机号登录层（验证码演示用，账号与验证码**不写在页面里**，
由演示者口头给出）。接真实后端时替换 `wxAuthorize` 与 `sendCode / verifyCode` 三处。

## 设置

- **外观模式**：跟随设备 / 浅色 / 深色，全站生效，存 `skl.theme`。
  强制模式靠 `assets/theme.css` 覆盖 `tokens.css` 的两套色值（逐字副本），
  页面里的深色媒体查询都带 `html:not([data-theme="light"])` 护栏。
- **自动播报**：只控对话页回复完成后的那一次播报，不含首页欢迎语，存 `skl.autospeak`。
  未登录时该行不显示。
- **退出登录**：二次确认 → 清 `skl.user` → 回首页（带 `?agreed=1`，不再重弹协议）。
  主题与播报偏好不清——它们与账号无关。

## 演示数据的边界

没有后端。登录态、主题、播报偏好走 `localStorage`，历史列表每次刷新重置为种子数据
（便于反复演示删除 / 改名）。首页每次加载会清 `skl.user`，让扫码授权这一段可复现。
对话回复是固定演示文案。

## 本地预览

Playwright 禁用 `file://`，需起本地服务器：

```bash
python -m http.server 8791
# 打开 http://127.0.0.1:8791/
```

`404.html` / `500.html` 按 DESIGN.md §4.4 状态页骨架写：居中单点、一个明确动作。
两者差别在「有没有重试价值」—— 404 重试无用，所以只给出口；
500 是暂时的，所以主动作是「重新加载」，出口降为次级链接。
**注意**：这两个文件名是演示用的静态页面，不等于真实 HTTP 状态码。
部署时需要在服务器侧把 404/500 指向这两个文件，静态托管（如 GitHub Pages）
会自动使用根目录的 `404.html`，`500.html` 需要自行配置。

## 约束速记（详见 h5v2/DESIGN.md）

- 颜色只用 `#hex` / `rgba()`。**禁止 `oklch()` / `color-mix()`** —— 微信 X5 旧内核不认，整条声明静默失效。
- 数值一律走令牌，页面里不写裸色值 / 裸字号 / 裸间距。字号只有 `--text-xs/base/md/lg/xl` 五档，没有 14px。
- 320px 视口不得横向溢出：`scrollWidth <= clientWidth`。
- 覆写 `base.css` 组件要提特异性（如 `.iconbtn.composer__mode` 而非 `.composer__mode`）。
- `showModal` 必须有 else 兜底；CSS 兜底放 `@supports not selector(dialog:modal)` 内。
- 数字人形象位是固定几何（首页基准 286px 大形象），字号不随档位在形象内放大。
  首页形象位在矮屏下按 `clamp()` 收缩至 190px 下限，以保证一屏叙事。
