# skl-h5-demo-2026

社科联二期项目建设（SKLQ2）H5 端演示原型仓库。

- 产品名称：湖北社科数据信息联盟
- 仓库用途：承载公众号 H5 端可运行原型
- 当前状态：首页、对话页（`chat.html`）、历史对话列表页（`history.html`）、
  我的账户（`account.html`，正文待补）、登录 / 注册、404 / 500 状态页已完成

## 目录

```
index.html                      首页 · Companion-Hero（数字人入口页）
chat.html                       对话页 · Companion-Chat（空对话 + 两态输入条）
history.html                    历史对话列表页 · 新建 / 切换 / 改名 / 删除
account.html                    我的账户（微信：身份只读；非微信：手机号 + 退出）
phone.html                      更换手机号（三级页，账户页身份行进入）
auth.js                         登录 / 注册（手机 + 短信验证码，非微信环境才生效）
assets/demo-qr.png              扫码引导用的演示二维码（占位，非真实链接）
404.html                        页面不存在（独立状态页）
500.html                        服务暂时不可用（独立状态页）
README.md                       本文件
h5v2/                           设计体系 v2「靖紫」，自包含副本
  tokens.css                      令牌唯一真源
  base.css                        基础层 + 组件层
  DESIGN.md                       规范正文
  index.html                      规范预览页
  assets/avatars/                 数字人形象占位素材
```

`404.html` / `500.html` 按 DESIGN.md §4.4 状态页骨架写：居中单点、一个明确动作。
两者差别在「有没有重试价值」—— 404 重试无用，所以只给出口；
500 是暂时的，所以主动作是「重新加载」，出口降为次级链接。
**注意**：这两个文件名是演示用的静态页面，不等于真实 HTTP 状态码。
部署时需要在服务器侧把 404/500 指向这两个文件，静态托管（如 GitHub Pages）
会自动使用根目录的 `404.html`，`500.html` 需要自行配置。

页面直接引用 `./h5v2/`，仓库自包含，单独 clone 即可运行。
`h5v2/` 的源目录在父仓库 `05-Design/design-system/h5v2/`，体系改动请回写那边。

## 演示账号

登录 / 注册（手机 + 短信验证码）**只在非微信浏览器出现**；微信内走公众号授权，
不显示该表单。

```
手机号：13800138000
验证码：123456
```

演示站没有后端，发不出真短信，所以手机号只认这一个、验证码是个常量。
**页面不显示这两个值** —— 演示时口头给出即可；点「获取验证码」后页面只说
「验证码已发送」，不露码。

三点说明：
- 两个值定义在 `auth.js` 顶部（`DEMO_PHONE` / `DEMO_CODE`），页面文件里没有。
  接真实后端时删掉 `submit()` 里的 `isDemoAccount()` 判断即可。
- **这不是安全边界**，只是演示时的一次性门槛 —— 翻源码就能看到，真要防得靠后端。
- 登录态存在 `localStorage['skl.user']`，跨页生效。想退回未登录，清掉这个键
  （或在控制台执行 `Auth.logout()`）。

## 账户页的两套形态

`account.html` 按环境分两套，同一份 HTML 由 `.is-wx` 切换：

| | 微信内 | 非微信 |
| --- | --- | --- |
| 返回钮 | 不显示（用微信 APP 原生导航） | 显示 |
| 身份行 | 微信头像 + 昵称，只读 | 默认头像（不可改）+ 脱敏手机号 + 箭头 → `phone.html` |
| 退出登录 | **不提供**（身份由公众号授权给，退出该由微信侧管） | 提供，二次确认后退出并回首页 |
| 服务协议 / 隐私条款 | 一栏两行，点击 toast 提示「链接待接入」（地址待定） | 同左 |

手机号脱敏保留前 4 与后 4（如 `1380***8000`）—— 不用固定 4 颗星，
那样不同位数的号码看起来一样、眼睛也没法校验长度。

改号页 `phone.html` 复用与登录弹层同一个 `.authcode` 行，校验规则与演示账号同源。

## 演示用查询参数

状态与数据都是演示实现，用查询参数可直达某一态，方便逐个验收。

| 页面 | 参数 | 作用 |
| --- | --- | --- |
| `chat.html` | `?q=<文本>` | 把该文本作为首条提问发出（首页键盘钮、转写弹窗的发送都走这条） |
| `history.html` | `?state=empty` | 空列表态 |
| `history.html` | `?state=loading` | 加载态（三行骨架，900ms 后落到真实列表） |
| `history.html` | `?state=error` | 加载失败态（点「重新加载」可恢复） |
| `history.html` | `?state=delfail` | 下一次删除强制失败一次，展示删除失败反馈 |
| `history.html` | `?state=reset` | 把对话列表恢复成初始演示数据 |
| `history.html` | `?from=chat` | 记录跳转来源，决定返回钮去向。取值 `chat` / `index`，未知值按层级回首页 |

对话列表存在 `localStorage['skl.convs']`，删除会真的落库、刷新仍在。

## 本地预览

Playwright 禁用 `file://`，需起本地服务器：

```bash
python -m http.server 8791 --bind 127.0.0.1
# 打开 http://127.0.0.1:8791/
```

## 约束速记（详见 h5v2/DESIGN.md）

- 颜色只用 `#hex` / `rgba()`。**禁止 `oklch()` / `color-mix()`** —— 微信 X5 旧内核不认，整条声明静默失效。
- 数值一律走令牌，页面里不写裸色值 / 裸字号 / 裸间距。
- 320px 视口不得横向溢出：`scrollWidth <= clientWidth`。
- 数字人形象位是固定几何（首页基准 286px 大形象 / 对话页 44px 顶栏头像），字号不随档位在形象内放大。
  首页形象位在矮屏下按 `clamp()` 收缩至 190px 下限，以保证一屏叙事。
