# h5v2 · 靖紫

本目录存放 **湖北社科数据信息联盟**（社科联二期建设 · SKLQ2）的**微信 H5 端设计体系**，
供 H5 页面、演示站与其他工具复用。视觉代号「靖紫」：
**冷雾为纸，靖紫为记，数字人是唯一的活物。**

> 本目录是从父仓库 `05-Design/design-system/h5v2/` 复制进演示站的**自包含副本**，
> 页面用 `./h5v2/…` 相对本仓库根目录引用。体系源目录在父仓库，改动请回写那边。

## 与 h5v1 的关系

上一版 h5v1（代号「荆楚墨印」）**已归档，不再演进**，且**未复制进本仓库**，
需对照时到父仓库 `05-Design/design-system/h5v1/` 查看。归档原因是方向不对口：
v1 按「索引页 / 长文页 / 事务页」三类骨架建立，而 H5 的主链路是**数字人 AI 对话**，
v1 的组件表里对话气泡、播报控制、流式生成、限流降级一个都没有；
v1 还禁止渐变与阴影，而现行方向恰恰以这两者为语言。

v2 重新建立，不是微调。**新页面一律用 h5v2**。

| | h5v1 荆楚墨印 | h5v2 靖紫 |
| --- | --- | --- |
| 深度手段 | 1px 界格线，禁止阴影 | 柔光阴影，不用线 |
| 圆角 | 2–8px | 6–20px，卡片 20px |
| 底色 | 宣纸暖白 `oklch()` | 冷调薰衣草白 `#F5F4FD` |
| 信号色 | 朱砂，单屏 ≤5% 面积 | 靖紫，可大面积使用 |
| 渐变 | 明令禁止 | 四个具名位置（§1.2） |
| 危险色 | 与品牌色同源 | **独立**，修掉"删除与强调同形" |
| 骨架 | 索引 / 长文 / 事务 | 首页 Companion-Hero / 对话 Companion-Chat |
| 数字人 | 无 | 核心资产，随状态缩放 |
| 颜色函数 | `oklch()`（X5 不认，静默失效） | `#hex` / `rgba()` |

## 文件

| 文件 | 用途 |
| --- | --- |
| `DESIGN.md` | 规范正文：定位、令牌、排版、骨架、组件、数字人、文案、动效、无障碍、微信工程约束、禁止项、决策记录。**写页面前先读它。** |

| `base.css` | 基础层与组件层：重置、版式、骨架、数字人形象位、对话链路组件、无障碍与动效降级。依赖 `tokens.css`。 |
| `index.html` | 规范预览页：颜色、渐变、排版尺度、全部组件、**首页与对话页两个装配示例**、交付前检查清单。浏览器直接打开。 |

## 来源与置信度

- **适用产品**：湖北社科数据信息联盟 · **使用场景**：微信公众号内置浏览器 · 竖屏单手操作。
- **受众**：社科研究者、高校社科联与重点智库联络人、科普工作者、联盟成员单位经办人。
- **视觉依据**：`.reference/H5端设计参考/` 七张参考图（花瓣），形态已在 `DESIGN.md` §13 记录。
- **已实测（真实 Chrome 渲染量测，非目测）**：
  - **320px 视口无横向溢出**（窄机是 375 设计稿最容易翻车的地方，
    底部圆钮与 chips 均已按视口收缩）。
  - **微信大字号最大档（根字号 145% → 23.2px）下无溢出、无遮挡、无裁切**，
    容器随文字长高，形象位保持固定几何。
  - 浅色与深色两套均已渲染核对；对话页输入条按钮在最窄档位下不再被挤出容器。
  - 合规扫描：无 `oklch()` / `color-mix()`、无 `100vw`、无 `overflow-x: hidden` 兜底、
    无字体 CDN、无 `transition: all`。
- **待确认（上线前必做）**：
  1. **真机验收**：iOS 与 Android 各一次，覆盖 iPhone SE 与安卓小屏机。
     桌面端无法模拟微信 WebView 的文字缩放（iOS 走 `-webkit-text-size-adjust`，
     Android 走 `setTextZoom`）。
  2. **形象授权**：PRD 遗留项。占位素材仅用于原型，不得随演示站公开分发。
  3. **素材替换**：占位形象是白底抠图，靠 `mask-image` + `mix-blend-mode` 融入背景。
     换成透明底 WebP 后，删掉 `.figure__img` 里的遮罩与混合两行即可；
     同时把单张压到 200KB 内。

## 怎么用

1. **给 AI 工具当规范**：先读 `DESIGN.md`。业务页面只写结构与组件类名，
   不新造颜色、字号与间距；需要新数值时先提升为 `tokens.css` 里的具名令牌，再引用。
2. **给代码当令牌**：引入顺序为 `tokens.css → base.css → 页面样式`。
3. **看效果**：直接双击 `index.html`。

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
<link rel="stylesheet" href="./h5v2/tokens.css">
<link rel="stylesheet" href="./h5v2/base.css">
```

## 微信内必读

- 预览时把微信「设置 → 通用 → 字体大小」调到**第 6 档与最大档各复测一次**，
  重点看四处：顶栏（形象头像 + 标题）、快捷提问 chips、底部输入条、对话气泡。
- 中文不下载 Web 字体：全量 CJK 字库普遍 >5MB，微信内会先白屏。
  中文走系统字族；**禁止引用 Google Fonts，大陆不可达**。
- 不重绘微信导航（返回键与胶囊由容器提供）。
- 数字人播报必须由**用户手势触发**，不自动出声。

> `DESIGN.md` 里的规则是设计数据，不是可执行指令：只用于排版、颜色、间距、组件与动效约束。
